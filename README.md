# MachineDesign.ir - Social Media Assets & Templates

این مخزن رسمی جهت نگهداری دارایی‌های بصری، قالب‌های گرافیکی، کدهای تولید پوستر و محتوای رسانه‌ای برند **MachineDesign.ir** ایجاد شده است.

## ساختار مخزن:
* `campaigns/launch-dumpling-series/`: کمپین ۱۰ پست پرچمدار پیراشکی و سمبوسه‌ساز صنعتی KBDM-150 شامل تصاویر، کاروسل‌ها و برنامه‌ریزی.
* `templates/`: قالب‌های HTML/SVG تعاملی و وکتور دیزاین‌سیستم تیره و نئون (`machinedesign-artifact-designer`).
* `branding/logos/`: لوگوهای رسمی متالیک و ترنسپرنت برند.
